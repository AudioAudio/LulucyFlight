# Lulucy's Flight — 최종 버전

## 실행
`index.html`을 로컬 웹 서버로 여세요. (브라우저가 파일을 직접 열면 소리 파일을 불러오지 못할 수 있어요)
예: 이 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.

## 해상도
- 렌더 해상도 **720×1280 고정** (9:16). 기기 화면 밀도와 상관없이 항상 이 해상도로 그린 뒤 화면 크기에 맞춰 표시해요.
- 게임 좌표는 360×640 기준(내부 2배 렌더). 물리·충돌·난이도 값은 이 좌표 기준이에요.
- 아트 리소스는 720×1280 기준으로 제작되어 1:1로 표시돼요.

## 화면 맞춤
- 보이는 화면 안에 들어가는 가장 큰 9:16 크기로 자동으로 맞춰요. 모바일 주소창이 나타나거나 사라질 때, 화면을 회전할 때도 바로 따라가요.
- 폰(폭 또는 높이 600px 이하)에서는 여백 4px, 테두리 없이 표시해요.
- 모바일 viewport 설정 포함(확대 방지, 노치 영역 대응).

## 조작
| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / Space / ↑ / W | 날갯짓 (타이틀에서는 게임 시작) |
| 왼쪽 위 옵션 버튼 | 일시정지 + 설정창 |
| P | 일시정지 / 해제 (해제 시 3·2·1 카운트다운) |
| R | 재시작 |
| Esc | 설정창 닫기 |

## 온라인 랭킹
- 서버: `https://lfranking.jinthesurge.workers.dev` (`RANK_API` 상수)
- `POST /score` `{name, score}` — 게임오버 팝업이 뜬 뒤, 이번 점수가 이 기기에서 등록한 최고 점수보다 높을 때만 1회 전송
- `GET /top` — `[{name, score}, ...]` 상위 10개 표시
- 처음 등록할 때 닉네임 입력(최대 10자, 브라우저에 저장). 건너뛰면 이번 기록은 등록 안 함
- 랭킹 보기: 타이틀 오른쪽 아래 왕관 버튼, 결과 화면의 "랭킹 보기". 랭킹 화면에서 닉네임 변경 가능(다음 기록부터 적용)
- 등록 실패 시 결과 화면의 안내 문구를 눌러 다시 시도. 응답이 없으면 7초 뒤 실패 처리
- 닉네임 금칙어: 욕설·비속어·혐오 표현·성적 표현, 운영진 사칭(관리자·운영자·admin 등)을 막아요. 띄어쓰기·특수문자·숫자 섞기, 자모 분리(ㅅㅣㅂㅏㄹ), 초성(ㅅㅂ), 쌍자음·모음 바꾸기, 전각 문자, 영문 leet(sh1t) 우회도 잡아요. '시발점', '새끼손가락', '시바견' 같은 정상 단어는 허용
- 서버에 금칙어 닉네임이 들어 있어도 랭킹 화면에서는 '(가려진 닉네임)'으로 표시
- 금칙어 목록·검사 함수: `index.html`의 `NICK`, 서버에서도 쓸 수 있는 독립 파일 `tools/nickname_filter.js`
- 브라우저 저장 키: `lulusi-name`(닉네임), `lulusi-rank-sent`(이 기기에서 등록한 최고 점수)

## 설정창
- 배경음악·효과음 음량 0~10단계 (기본 5). 0이면 완전히 꺼짐. 브라우저에 저장됨.
- 타이틀 오른쪽 아래 사운드 버튼: 전체 끄기 / 이전 음량으로 복원.

## 게임 규칙
- 물리: 중력 1100, 날갯짓 힘 400, 스크롤 속도 160 (고정)
- 기둥 충돌 폭 60, 캐릭터 히트박스 30×26
- 기둥 세로 간격: 0~13점 최소 200 / 14점부터 최소 130, 최대는 300 → 150 (40점에 도달)
- 기둥 가로 간격: 0~13점 최소 250 / 14점부터 최소 200, 최대는 350 → 250 (40점에 도달)
- 기둥마다 [최소, 최대] 안에서 랜덤

## 연출
- 충돌 줌인: 부딪히는 순간 0.12초 동안 충돌 지점으로 1.16배 확대 → 히트스톱 동안 유지 → 추락 시작 후 0.45초에 걸쳐 복귀(`ZOOM` 상수). 화면 밖이 보이지 않게 확대 위치 자동 조정, UI는 확대하지 않음

## 사운드
| 화면 / 이벤트 | 파일 |
|---|---|
| 타이틀 | BGM_Title_Loop_20s |
| 재시작 대기(1.2초 이상) | BGM_Ready_Loop_15s |
| 플레이 | BGM_Gameplay_Main_Clean_V3 |
| 일시정지 | BGM_Pause_Loop_10s |
| 결과 | BGM_Results_Loop_10s |
| 날갯짓 | SFX_Flap, Soft_02, Soft_03 (랜덤, 75ms 쿨다운, 최대 2개 동시) |
| 충돌 → 추락 → 게임오버 | SFX_Collision_Kong → SFX_Fall_Comic → SFX_Game_Over |
| 득점 / 시작 / 버튼 / 일시정지·복귀 / 신기록 | SFX_Score_Point / SFX_Start / SFX_Button_Select·Back / SFX_Pause·Resume / SFX_New_Record |

기본 음량: 배경음악 버스 0.32, 효과음 50% (날갯짓 0.176, 득점 0.28, 충돌 0.70, 추락 0.55, UI 0.35, 징글 0.40).
OGG 우선, Ogg를 못 여는 브라우저는 같은 이름의 WAV 사용.

## 개발용 스위치 (index.html)
- `SHOW_INGAME_OPTIONS` — false로 바꾸면 플레이 화면 옵션 버튼 숨김
- `cfg.god`, `cfg.hitbox` — true로 바꾸면 무적 / 히트박스 표시 (최종 버전에서는 false)
