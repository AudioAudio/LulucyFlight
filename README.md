# Lulucy's Flight — 최종 버전

## 실행
`index.html`을 로컬 웹 서버로 여세요. (브라우저가 파일을 직접 열면 소리 파일을 불러오지 못할 수 있어요)
예: 이 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.

## 조작
| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / Space / ↑ / W | 날갯짓 (타이틀에서는 게임 시작) |
| 왼쪽 위 옵션 버튼 | 일시정지 + 설정창 |
| P | 일시정지 / 해제 (해제 시 3·2·1 카운트다운) |
| R | 재시작 |
| Esc | 설정창 닫기 |

## 설정창
- 배경음악·효과음 음량 0~10단계 (기본 5). 0이면 완전히 꺼짐. 브라우저에 저장됨.
- 타이틀 오른쪽 아래 사운드 버튼: 전체 끄기 / 이전 음량으로 복원.

## 게임 규칙
- 물리: 중력 1100, 날갯짓 힘 400, 스크롤 속도 160 (고정)
- 기둥 충돌 폭 60, 캐릭터 히트박스 30×26
- 기둥 세로 간격: 0~13점 최소 200 / 14점부터 최소 130, 최대는 300 → 150 (40점에 도달)
- 기둥 가로 간격: 0~13점 최소 250 / 14점부터 최소 200, 최대는 350 → 250 (40점에 도달)
- 기둥마다 [최소, 최대] 안에서 랜덤

## 사운드
| 화면 / 이벤트 | 파일 |
|---|---|
| 타이틀 | BGM_Title_Loop_20s |
| 재시작 대기(1.2초 이상) | BGM_Ready_Loop_15s |
| 플레이 | BGM_Gameplay_Main_Clean_V3 |
| 일시정지 | BGM_Pause_Loop_10s |
| 결과 | BGM_Results_Loop_10s |
| 날갯짓 | SFX_Flap, Soft_02, Soft_03 (랜덤, 75ms 쿨다운, 최대 2개 동시) |
| 충돌 → 추락 → 게임오버 | SFX_Collision_Kong → SFX_Fall_Comic → SFX_Game_Over |
| 득점 / 시작 / 버튼 / 일시정지·복귀 / 신기록 | SFX_Score_Point / SFX_Start / SFX_Button_Select·Back / SFX_Pause·Resume / SFX_New_Record |

기본 음량: 배경음악 버스 0.32, 효과음 50% (날갯짓 0.176, 득점 0.28, 충돌 0.70, 추락 0.55, UI 0.35, 징글 0.40).
OGG 우선, Ogg를 못 여는 브라우저는 같은 이름의 WAV 사용.

## 개발용 스위치 (index.html)
- `SHOW_INGAME_OPTIONS` — false로 바꾸면 플레이 화면 옵션 버튼 숨김
- `cfg.god`, `cfg.hitbox` — true로 바꾸면 무적 / 히트박스 표시 (최종 버전에서는 false)
